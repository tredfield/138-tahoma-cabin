# 138 Tahoma St E — the cabin in 3D

Interactive Three.js framing drawings of the cabin at 138 Tahoma St E, Packwood WA (permit B26-00013),
published with GitHub Pages at https://tredfield.github.io/138-tahoma-cabin/.

- `index.html` — landing page
- `front-porch.html` — front porch, upper deck and roof extension (south end)
- `rear-deck.html` — rear deck, window wall and roof extension (north end)
- `img/` — hero and card images

Each drawing is a single self-contained file (Three.js r160 and OrbitControls inlined, MIT). Append
`?view=<name>`, `&show=<layers>`, `&hide=<layers>` or `&ui=0` to a drawing's URL to open it on a given view
and layer set. These are interpretive framing drawings, not engineered drawings — do not build from them.
