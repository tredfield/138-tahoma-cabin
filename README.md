# 138 Tahoma St E, Packwood -- front porch, upper deck and roof extension (3D)

Interactive structural-framing model of the south (front) end of the cabin: gable-end wall framing,
the entrance porch, the upper deck, and the steep main-gable roof carried out over them.

Open it here: https://tredfield.github.io/138-tahoma-cabin/

Drag to orbit, pinch or scroll to zoom, two-finger drag to pan. Use the view buttons and the layer
checkboxes at the bottom. Orange labels mark items still pending the engineer.

**Not an engineered drawing. Do not build from it.** Glulam sizes, hardware shapes, grade and the
rake-extension members are placeholders. Single self-contained file (Three.js inlined, no network needed).
